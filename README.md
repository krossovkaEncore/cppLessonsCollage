# C++ — Изучение в колледже

Репозиторий с учебными материалами по **C++**, изучаемому в рамках программы колледжа.

Здесь хранятся программа занятий, заметки по пройденным темам и выполненные домашние задания.

## 📁 Структура репозитория

```text
.
├── program.py    # Программа занятий и содержание уроков
├── dz/           # Домашние задания
│   ├── 23.11.2026.md
│   ├── 25.11.2026.cpp
│   └── ...
└── README.md
```

## 📚 Программа обучения

Файл `program.py` содержит программу курса. В нём с помощью `match/case` организован список занятий с описанием тем и пройденного материала.

## 📝 Домашние задания

Директория `dz/` содержит выполненные домашние задания.

Каждое задание хранится в отдельном файле, название которого соответствует дате выполнения.

Поддерживаемые форматы:

- `.cpp` — исходный код программ на C++.
- `.md` — текстовые ответы, теория и дополнительные заметки.

## 🎯 Цель проекта

- Систематизировать учебные материалы.
- Сохранять историю изучения C++.
- Отслеживать пройденные темы.
- Хранить решения домашних заданий в одном месте.
